# 🐺 人狼ゲーム

対面での人狼ゲームの進行管理と盤面整理をリアルタイムでサポートするWebアプリです。

▶ [アプリを開く](https://werewolf-game-gwl8.onrender.com/)

## 概要

GM（ゲームマスター）が部屋を作成し、参加者が6桁のゲームコードを入力して各自のスマホから参加します。全員の手元に生存状況やCO（カミングアウト）、占い結果がリアルタイムで共有され、初心者でもスムーズに推理を楽しめるよう設計されています。

## 機能

- 6桁のゲームコードによるルーム作成・リアルタイム参加
- 参加人数に応じた役職配分・各フェーズのタイマー秒数設定
- 全員の画面にリアルタイム同期される盤面共有ボード（生存状況・CO・結果メモ）
- GM管理パネル（タイマー停止/再開・時間増減・フェーズ強制スキップ・昼表示切替）
- 確白プレイヤー等への誤投票を防ぐ投票ロック機能と未行動防止ストッパー
- 夜フェーズでの人狼専用リアルタイムチャット（0日目〜毎晩対応・GM閲覧可）
- 周囲からの覗き見を防ぐ役職・結果履歴のタップ開閉機能とリロード時の自動再接続

## 使用技術

| 技術 | 用途 |
| :--- | :--- |
| HTML / CSS / JavaScript | フロントエンド（`public/index.html`） |
| Node.js / Express | バックエンドサーバー（`server.js`） |
| Socket.IO | 複数端末間のリアルタイム通信・タイマー同期 |
| SessionStorage | 端末・タブごとのセッション保持と自動再接続 |
| Render | ホスティング |

## ローカルでの実行

```bash
git clone https://github.com/Anzai-0916/werewolf-app.git
cd werewolf-app
npm install && npm start
# http://localhost:3000 をブラウザで開くだけで動作
```

実際の対面プレイで見えた課題をもとに、盤面共有ボードやGMの進行アシスト機能を実装し、`package.json` / `server.js` / `public/index.html` の3ファイル構成にまとめています。現場での操作性と視認性の向上を目的としています。
